# Sensore – Health Monitoring Web Application

Sensore is a healthcare monitoring web application developed as a university Software Engineering team project at Anglia Ruskin University.

The application processes pressure-sensor data and presents it through an accessible patient interface, helping users understand pressure distribution, identify high-pressure areas, monitor key metrics and communicate relevant information with clinicians.

## Key Features

- Interactive pressure-distribution heat map
- Patient authentication and account access
- Pressure monitoring and health metrics
- High-pressure notifications and alerts
- Patient and clinician communication
- Historical pressure-data visualisation
- User-friendly dashboards and reports
- Responsive patient interface

## Software Architecture

Sensore follows the Model-View-Controller (MVC) architecture.

- **Models** manage application data such as users, pressure readings, reports, comments and alerts.
- **Views** present dashboards, heat maps, reports and other information to users.
- **Controllers** handle application logic and communication between the models and views.

## Pressure Data Visualisation

One of the core features of Sensore is its interactive pressure heat map.

Sensor readings are processed and visually represented so patients can quickly identify areas experiencing higher pressure. The system also calculates useful metrics including:

- Peak Pressure Index
- Contact Area
- Average Pressure
- Distribution Score

The interface uses clear colours, labels and simple language to make health information easier to interpret.
